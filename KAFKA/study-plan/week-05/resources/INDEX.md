## Gợi ý thứ tự đọc

1. **Schema Registry core (1 → 2 → 3):** đọc wire format + serializer config trước (bẫy "5 byte lạ", `auto.register.schemas`), rồi compatibility (bảng thao tác + thứ tự nâng cấp — cụm hỏi nhiều nhất), rồi REST API để làm Lab 5.1–5.2 (409, `/compatibility`, `/config/<subject>`).
2. **Connect nền tảng (4 → 5):** khoá Kafka Connect 101 cho bức tranh worker/connector/task + converter vs serializer; sau đó User Guide để thuộc standalone vs distributed, 3 internal topic 1/25/5, REST API và trạng thái task (Lab 5.3, 5.7).
3. **Biến đổi & lỗi (6 → 7):** SMT/predicate cho Lab 5.4; error handling + DLQ cho Lab 5.5 — nhớ **DLQ chỉ sink**.
4. **Nâng cao (8 → 9):** KIP-618 để phân biệt offset source/sink và EOS source (câu hỏi "duplicate sau crash"); Debezium để nhận diện CDC (`op`, tombstone) và chuẩn bị outbox pattern ở Tuần 9.
5. Đọc lại **mục 🎯 Điểm thi quan trọng** của cả 9 file trong 15 phút trước khi làm [questions.md](../questions.md).

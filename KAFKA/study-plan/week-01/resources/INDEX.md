## Gợi ý thứ tự đọc

1. **Nền khái niệm (1):** đọc phần Introduction để thuộc câu chữ gốc — "events are not deleted after consumption", "same key → same partition", "order within a topic-partition", "replication factor of 3". Chạy lại quickstart trong đầu: `random-uuid` → `format --standalone` → `server-start`.
2. **Vì sao Kafka nhanh & bền (2):** Design → hiểu pagecache/zero-copy/batching để trả lời câu "why"; phần Replication là gốc của Tuần 2 (ISR, committed, f+1, `unclean.leader.election.enable`, `min.insync.replicas`).
3. **Trên đĩa có gì (3):** đối chiếu với Lab 1.5 — tên segment = base offset, `.index` thưa 4096 B, xoá cả segment, RecordBatch header (`producerId`… sẽ dùng ở Tuần 3 idempotence/transactions).
4. **KRaft vận hành (4 → 7):** đọc Operations trước để thuộc lệnh; sau đó đọc KIP-500/Confluent để trả lời câu "lý do bỏ ZooKeeper" và "active controller / observer / snapshot"; cuối cùng KIP-853 để phân biệt `controller.quorum.voters` vs `controller.quorum.bootstrap.servers`.
5. **Config & bẫy kết nối (5):** tra bảng default khi làm câu hỏi số liệu; đọc kỹ phần Docker trap — đề CCDAK và phỏng vấn hỏi rất nhiều về `advertised.listeners`.
6. **Điểm mới 4.x (6):** đọc cuối cùng, ghi ra giấy bảng KIP ↔ version (848 GA 4.0, 932 EA 4.0 → GA 4.2, 966 preview 4.0 → 4.1, 1030 `linger.ms=5`, Java 17/11, baseline 2.1) — đề mới cập nhật rất hay hỏi.
